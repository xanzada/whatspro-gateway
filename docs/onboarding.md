# Жаңа фаст-фуд желісін қосу

Бәрі бір беттен жасалады: **https://whatspro.bekaba.com/tenants**

Бет телефонға да ыңғайлы. Барлық конфигурация WhatsPro платформасының Redis
қоймасында оқшауланып сақталады; токендер, құпия кілттер және қызметтік
мекенжайлар өздігінен жасалады.

## Қадамдар

1. `/tenants` бетін ашыңыз → **«+ Қосу»**.
2. Атауын жазасыз — Instance ID мен домен өздігінен толтырылады.
3. WhatsApp нөмірін және мекенжайын қосасыз.
4. Промпт: **Ортақ** (барлығына бір мәтін) немесе **Жеке** (тек осы нысанға).
5. **«Қосу»** → QR-кодты сканерлейсіз немесе уақытша қосылу сілтемесін клиентке жібересіз.
6. `/tenants` бетінде шам жасыл болса — дайын.

## Өзіңіз шешетін өрістер

| Өріс | Мәні |
| --- | --- |
| Атауы | Клиент көретін және чат тақырыбында тұратын атау |
| Instance ID | Атауынан өзі жасалады (`Crazy суши` → `crazy-sushi`). Қолмен түзетуге болады, кейін өзгермейді |
| WhatsApp нөмірі | Ботқа тиесілі нөмір. **Әр нысанда бөлек болуы міндетті** |
| Сайт домені | Instance ID-ден өзі жасалады. Басқа домен болса — қолмен жазасыз |
| Мекенжайы | Өзі келіп алу және мекенжай сұрақтары үшін |
| Жұмыс уақыты | «Қашан ашықсыңдар?» сұрағының жауабы |
| Әкімші нөмірі | Бос қалса WhatsApp нөмірі қойылады |
| Промпт | Ортақ немесе жеке |

## Платформа өзі жасайтындар

Бұларға тиіспейсіз — әрқайсысы кездейсоқ, әр ресторанда бөлек:

`whatspro_api_token`, `webhook_secret`, `kanban_secret`, `crm_secret_token`,
`whatspro_base_url`, `whatspro_send_url`, `whatspro_presence_url`, `dev_phone`.

Кілттерді қайта жасау керек болса — ресторан картасындағы **«Кілт жаңарту»**.

## Ортақ промпт

Жоғарыдағы **«Ортақ промпт»** батырмасы. Сақтағанда мәтін *Ортақ* режимдегі
барлық ресторанға жазылады. *Жеке* режимдегілерге тимейді — өз мәтінін жазған
ресторан оны жоғалтпайды.

## Ресторанды басқару

Әр картаны басқанда ашылады:

- **Өңдеу** — өрістерін өзгерту
- **Тоқтату / Іске қосу** — WhatsApp сессиясын өшіреді/қосады. Тоқтатылғанда
  хабар мүлдем келмейді, сондықтан бот қате жауап бере алмайды
- **Клон** — параметрлерін көшіріп жаңа филиал жасайды. Нөмір мен Instance ID
  көшірілмейді, кілттер жаңадан жасалады
- **Кілт жаңарту** — барлық құпия кілттерді ауыстырады
- **Өшіру** — кестеден де, WhatsApp сессиясынан да жояды. Instance ID-ін жазып
  растау керек

## Ресторандар арасындағы қақтығыс

Бір жолды жеке қарап тұрып көрінбейтін, бірақ 50 ресторанда ең қауіпті үш қате.
Бет кестенің бәрін салыстырып, оларды жоғарыда қызыл блокпен шығарады:

- **бір WhatsApp нөмірі екі ресторанда** — клиенттің хабары басқа ресторанға түседі;
- **бір API токен екі ресторанда** — бірі екіншісінің чатын аша алады;
- **бір Instance ID екі жолда** — қай жол оқылатыны кепілдендірілмейді.

Біреуі шықса, екі ресторан да «дайын емес» болып саналады.

## API арқылы

Бет ашпай, скрипттен басқару керек болса — бәрі платформа токенімен ашылады:

```bash
H="x-api-key: $WHATSPRO_API_TOKEN"
B=https://whatspro.bekaba.com

curl -H "$H" $B/api/wa/tenants                     # бәрінің дайындығы
curl -H "$H" $B/api/wa/tenants/prestige            # біреуінің егжей-тегжейі
curl -H "$H" $B/api/wa/tenants/prestige/settings   # өрістері (кілтсіз)

curl -H "$H" -H 'Content-Type: application/json' -X POST $B/api/wa/tenants \
  -d '{"brand":"Crazy суши","whatsappPhone":"77015550101"}'

curl -H "$H" -H 'Content-Type: application/json' -X POST $B/api/wa/tenants/prestige/active -d '{"active":false}'
curl -H "$H" -H 'Content-Type: application/json' -X POST $B/api/wa/tenants/prestige/clone  -d '{"brand":"Екінші филиал","whatsappPhone":"77015550202"}'
curl -H "$H" -X POST $B/api/wa/tenants/prestige/rotate
curl -H "$H" -H 'Content-Type: application/json' -X DELETE $B/api/wa/tenants/prestige -d '{"confirm":"prestige"}'
```

Нысанның өз токені бұл жерге жарамайды — тізім барлық нысанды көрсететін
болғандықтан, ол тек платформа токенімен ашылады.

## Күшіне ену уақыты

WhatsPro өзгерісті Redis қоймасына бірден жазады. OpenBot негізгі конфигурацияны
WhatsPro API-інен алады; bot pause/resume басқаруы екі секундтық қысқа control
кэшімен тексеріледі. WhatsApp сессиясы pause кезінде үзілмейді.
